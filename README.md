# 🎬 CineFlix  (🧪 Experimental project. Not production-ready and no longer actively developed)

A modern movie booking app built for speed, elegance, and developer happiness.

## 🚀 Tech Stack

- ⚛️ **Next.js** – Server components & App Router  
- 🧠 **TypeScript** – Static type safety  
- 🎨 **shadcn/ui** – Beautiful and accessible components  
- 🧵 **Tailwind CSS** – Utility-first styling  
- 🗃️ **PostgreSQL** – Relational DB  
- 🛠️ **Prisma** – Type-safe ORM

## ✅ Features

- 🔍 Browse movies with real-time filtering  
- 🎫 Book tickets effortlessly  
- 🧾 Track bookings (if auth enabled)  
- 📅 Organized showtimes and dynamic listings  
- ✨ Fully styled with shadcn + Tailwind

## 📦 Getting Started

```bash
git clone https://github.com/yourusername/cineflix.git
cd cineflix
pnpm install
pnpm dev
```
